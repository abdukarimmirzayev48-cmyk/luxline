DESIGN RULES (strict)
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━
- NO rounded corners anywhere (sharp = luxury)
- NO drop shadows — use borders and negative space instead
- NO gradients except hero overlay
- All images: high-contrast, cinematic, dark photography only
- Hover micro-animations: 250ms ease, subtle gold underlines, 
  opacity shifts
- Spacing system: 8px base grid, 
  section padding top/bottom = 120px
- Max content width: 1280px, centered
- All section transitions: clean hard cuts, no wave shapes
- Mobile: stack all columns, maintain gold accents, 
  reduce heading sizes by 40%
